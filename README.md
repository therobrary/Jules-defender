# Neon Defender

A retro arcade shooter clone inspired by the classic **Defender**. Built with Vanilla JavaScript and HTML5 Canvas.

## How to Play

Defend your sector from the alien Landers!

1.  **Start:** Click "INITIATE SYSTEM" to begin.
2.  **Fly:** Use **Arrow Keys** to move and thrust.
    *   **Left/Right:** Thrust horizontally (momentum-based).
    *   **Up/Down:** Change altitude.
3.  **Fire:** Press **Spacebar** to shoot lasers.
4.  **Radar:** Keep an eye on the minimap at the top to spot off-screen enemies.
5.  **Goal:** Destroy all enemies to advance to the next wave. Don't crash into them!

### Mobile Controls
*   **Left Side:** Virtual Joystick (Slide thumb to move).
*   **Right Side:** Fire Button (Tap to shoot).

## Features
*   Smooth 60FPS vector graphics.
*   Infinite horizontal scrolling with world wrapping.
*   Particle explosions and neon visual effects.
*   Web Audio API synthesized sound effects.
*   Responsive design for Desktop and Mobile.
